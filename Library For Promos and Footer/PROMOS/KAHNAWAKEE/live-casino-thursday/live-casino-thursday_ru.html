Правила и условия

1. Данная акция действует для ставок, сделанных в четверг с ${start_time} ${timezone} до ${end_time} ${timezone}.

2. Cashback-бонус будет зачислен на счета клиентов в течение следующего календарного дня.

3. Это предложение доступно для новых и существующих игроков.

4. На одного человека, владельца счета, IP-адрес, домохозяйство, адрес, номер телефона, банковский счет (включая кредитную карту, электронный кошелек и т. д.) может быть начислен только один бонус.

5. Игроки делают ставки в любой из доступных игр Live Casino в период действия акции и получают право на кешбэк в размере ${percentage} на проигрыш реальных денег.

6. Проигрыши на реальные деньги рассчитываются как "Сумма ставок на реальные деньги в Live Casino - Выигрыш на реальные деньги по этим ставкам". Ставки, сделанные с помощью бонусных денег, не учитываются в данной акции

7. Максимальная награда в результате этой акции для одного игрока составляет ${amount}. Минимальная награда в результате данной акции для одного игрока составляет ${min_award}.

8. Суммы кэшбэка будут начисляться в виде бонуса казино. Они будут автоматически добавляться в раздел "Доступные" бонусы и могут быть активированы только игроком.

9. Бонус будет доступен для активации в течение 7 дней в разделе "Доступные" бонусы, после чего он истечет.

10. Бонус сопровождается требованием по отыгрышу в размере ${wagering_req} суммы бонуса.

11. Отчисления на отыгрыш для выполнения требований бонуса составляют:

a. Рулетка: 20%

b. Баккара: 5%.

c. Блэкджек: 10%

d. Другое: 10%

12. После активации бонуса требование по отыгрышу должно быть выполнено в течение 7 дней, в противном случае бонус и все полученные выигрыши будут аннулированы.

13. Минимальная сумма ставки, которую вы можете сделать, пока у вас есть активный бонус, составляет ${min_bet} на спин/бет. Спины/ставки меньше ${min_bet} не будут учитываться в требованиях по отыгрышу бонуса, и любой потенциальный выигрыш будет аннулирован.

14. Максимальная сумма ставки, которую вы можете сделать, пока у вас есть активный бонус, составляет ${max_bet} на спин/бет. Спины/ставки, превышающие ${max_bet}, не будут учитываться в требованиях по отыгрышу бонуса, а любые потенциальные выигрыши будут аннулированы.

15. Любая попытка накопить стоимость функции в любой игре при активном бонусе, а затем отыграть ее, когда требование отыгрыша бонуса не действует, чтобы получить стоимость, выплаченную в виде реальных денег, будет считаться мошеннической игрой, а любой выигрыш будет конфискован. Например, игра с активным бонусом, активация внутриигровой функции, выход из игры, возвращение и получение выплаты по функции после того, как бонус закончится.
