Πώς μπορώ να δημιουργήσω έναν λογαριασμό;

Απλά κάντε κλικ στο κουμπί "Εγγραφή" και ακολουθήστε τις οδηγίες.

Πώς μπορώ να κλείσω τον λογαριασμό μου;

Εάν επιθυμείτε να κλείσετε τον λογαριασμό σας, παρακαλούμε επικοινωνήστε με την ομάδα υποστήριξης πελατών μας, η οποία θα χαρεί να σας βοηθήσει σε αυτό.

Πώς μπορώ να αλλάξω τη διεύθυνση email μου;

Παρακαλούμε επικοινωνήστε με την ομάδα υποστήριξης πελατών μας μέσω ζωντανής συνομιλίας ή ηλεκτρονικού ταχυδρομείου, η οποία θα χαρεί να σας βοηθήσει.

Πώς μπορώ να αλλάξω τον κωδικό πρόσβασής μου;

Απλά κάντε κλικ στο "Σύνδεση" και στη συνέχεια στο "Ξεχάσατε τον κωδικό πρόσβασής σας;" και ακολουθήστε τις οδηγίες.

Ποιος μπορεί να δημιουργήσει λογαριασμό;

Σημειώστε ότι μπορείτε να δημιουργήσετε λογαριασμό μόνο στο όνομά σας. Δεν επιτρέπεται να ανοίξετε λογαριασμούς για κάποιον άλλο ή να εργαστείτε ως πράκτορας. Οποιοσδήποτε είναι άνω των 18 ετών και δεν είναι κάτοικος αυτών των χωρών: Ηνωμένο Βασίλειο, ΗΠΑ και Ελλάδα.

Γιατί δεν μπορώ να δημιουργήσω λογαριασμό;

Βεβαιωθείτε ότι έχετε συμπληρώσει σωστά όλα τα πεδία της διαδικασίας εγγραφής και ότι δεν υπάρχουν σφάλματα. Λάβετε επίσης υπόψη ότι δεν επιτρέπεται να έχετε περισσότερους από 1 λογαριασμούς ανά άτομο/IP/διεύθυνση ή νοικοκυριό.

Αν έχετε ήδη λογαριασμό, αλλά δεν θυμάστε τον κωδικό πρόσβασης, τότε απλά κάντε κλικ στο κουμπί Σύνδεση > Ξεχάσατε τον κωδικό σας; και ακολουθήστε τις οδηγίες.

Θα μπορούσατε επίσης να δοκιμάσετε να χρησιμοποιήσετε ένα άλλο πρόγραμμα περιήγησης στο διαδίκτυο, αυτό μπορεί μερικές φορές να είναι το πρόβλημα.

Εάν κανένα από τα παραπάνω δεν σας βοηθάει, είστε ευπρόσδεκτοι να επικοινωνήσετε με την ομάδα υποστήριξης πελατών μας μέσω ζωντανής συνομιλίας ή ηλεκτρονικού ταχυδρομείου και θα χαρούμε να σας βοηθήσουμε.

Πώς μπορώ να αλλάξω τα στοιχεία του λογαριασμού μου;

Απλά κάντε κλικ στο avatar σας στο αριστερό μενού για να αποκτήσετε πρόσβαση στο λογαριασμό σας. Στη συνέχεια, ενημερώστε τα στοιχεία του λογαριασμού σας στην ενότητα "Προφίλ".

Μόλις δημιούργησα έναν λογαριασμό, αλλά δεν μπορώ να συνδεθώ;

Ελέγξτε δύο φορές τη διεύθυνση ηλεκτρονικού ταχυδρομείου και τα στοιχεία του λογαριασμού σας.

Αν δεν είστε σίγουροι για τον κωδικό πρόσβασής σας, κάντε κλικ στο κουμπί Σύνδεση > Ξεχάσατε τον κωδικό πρόσβασής σας; και ακολουθήστε τις οδηγίες.

Εάν έχετε προσπαθήσει να συνδεθείτε αρκετές φορές χρησιμοποιώντας λάθος στοιχεία, μπορεί ο λογαριασμός σας να έχει κλειδωθεί προσωρινά για λόγους ασφαλείας.

Παρακαλούμε επικοινωνήστε με την ομάδα υποστήριξης πελατών μας, η οποία θα χαρεί να σας βοηθήσει.

Δεν μπορώ να συνδεθώ, τι συμβαίνει;

Πρώτον, ελέγξτε δύο φορές ότι χρησιμοποιείτε τη σωστή διεύθυνση ηλεκτρονικού ταχυδρομείου και τα σωστά στοιχεία λογαριασμού για να συνδεθείτε.

Αν δεν είστε σίγουροι για τον κωδικό πρόσβασής σας, κάντε κλικ στο κουμπί Σύνδεση > Ξεχάσατε τον κωδικό πρόσβασής σας; και ακολουθήστε τις οδηγίες.

Εάν έχετε προσπαθήσει να συνδεθείτε αρκετές φορές χρησιμοποιώντας λάθος στοιχεία, μπορεί ο λογαριασμός σας να έχει κλειδωθεί προσωρινά για λόγους ασφαλείας.

Παρακαλούμε επικοινωνήστε με την ομάδα υποστήριξης πελατών μας, η οποία θα χαρεί να σας βοηθήσει.

Πώς μπορώ να επαληθεύσω τον λογαριασμό μου;

Μόλις δημιουργήσετε το λογαριασμό σας, είναι πάντα καλή ιδέα να ολοκληρώσετε την επαλήθευση. Αυτό γίνεται μεταβαίνοντας στις ρυθμίσεις του λογαριασμού σας και στη συνέχεια στην ενότητα εγγράφων, όπου απλώς ακολουθείτε τις οδηγίες και ανεβάζετε τα απαιτούμενα έγγραφα. Αφού τα φορτώσετε, τα έγγραφά σας θα εξεταστούν από την ομάδα μας, και μόλις τα έγγραφά σας επαληθευτούν, θα ενημερωθείτε.

Η έγκαιρη επαλήθευση του λογαριασμού σας θα σας βοηθήσει να αποφύγετε αυτό το βήμα όταν θα θέλετε να κάνετε ανάληψη χρημάτων και να διασφαλίσετε μια πιο ομαλή εμπειρία.

Εάν έχετε οποιεσδήποτε ερωτήσεις, παρακαλούμε επικοινωνήστε με την ομάδα υποστήριξης πελατών μας μέσω ζωντανής συνομιλίας ή ηλεκτρονικού ταχυδρομείου. Για να μπορέσουμε να επαληθεύσουμε τον λογαριασμό σας, θα πρέπει να ανεβάσετε τα ακόλουθα έγγραφα:

Αποδεικτικό ταυτότητας, το οποίο μπορεί να είναι ένα από τα ακόλουθα:

- Εθνική ταυτότητα

- Διαβατήριο

- Άδεια οδήγησης

Προκειμένου να επαληθευτεί η διεύθυνσή σας, παρακαλούμε να μας προσκομίσετε μια φωτογραφία ολόκληρης της σελίδας ενός αποδεικτικού διεύθυνσης που έχει εκδοθεί στο όνομά σας, εντός των τελευταίων 3 μηνών. Τα αποδεκτά έγγραφα είναι οι τραπεζικές καταστάσεις/καταστάσεις καρτών με τις τελευταίες σας συναλλαγές και λογαριασμοί κοινής ωφέλειας, όπως λογαριασμοί ηλεκτρικού ρεύματος, νερού, σταθερής τηλεφωνίας, φυσικού αερίου, θέρμανσης, κινητής τηλεφωνίας. Δεν δεχόμαστε επιστολές, αποδείξεις, σημειώματα, υποθήκες, δάνεια, καταστάσεις τελών, ασφάλειες, συνταγές, τηλεοπτικές άδειες, εκκαθαριστικά σημειώματα ή τίτλους οχημάτων ως αποδεικτικά στοιχεία της διεύθυνσής σας.

Μια απόδειξη των κεφαλαίων, ανάλογα με τη μέθοδο κατάθεσης:

Για την επαλήθευση της κάρτας σας, γίνονται δεκτά τα ακόλουθα έγγραφα:

- Φωτογραφία της κάρτας σας. Σημειώστε ότι τα πρώτα 6 και τα τελευταία 4 ψηφία πρέπει να είναι ορατά, καθώς και το όνομα του κατόχου της κάρτας και η ημερομηνία λήξης. Για την επαλήθευση του ηλεκτρονικού σας πορτοφολιού, γίνονται δεκτά τα ακόλουθα έγγραφα:

- Στιγμιότυπο του λογαριασμού ηλεκτρονικού πορτοφολιού σας με όλα τα στοιχεία του λογαριασμού ορατά. Για την επαλήθευση του IBAN σας, γίνονται δεκτά τα ακόλουθα έγγραφα:

- Κατάσταση λογαριασμού ή επίσημο τραπεζικό έγγραφο στο οποίο αναγράφονται σαφώς ο IBAN και το όνομα του κατόχου του λογαριασμού. Σημειώστε ότι τα έγγραφα που δεχόμαστε είναι συγκεκριμένα και θα πρέπει να είναι σε μορφή PDF ή φωτογραφίες φυσικού αντιγράφου. Δεν μπορούμε να δεχτούμε στιγμιότυπα οθόνης κινητού τηλεφώνου, περικομμένα ή σαρωμένα αρχεία.

Όλα τα έγγραφα πρέπει να μεταφορτωθούν στο λογαριασμό σας στο παιχνίδι και να είναι σε μορφή jpeg, png ή pdf. Κάθε αρχείο που ανεβάζετε δεν πρέπει να υπερβαίνει τα 3MB σε μέγεθος.

Για να φορτώσετε τα έγγραφά σας, κάντε κλικ στο εικονίδιό σας -> Το προφίλ μου - > καρτέλα Έγγραφα -> Επιλέξτε τον τύπο του εγγράφου -> Επιλέξτε αρχείο -> Επαλήθευση.

Σας ευχαριστούμε εκ των προτέρων για τη συνεργασία σας και ανυπομονούμε να λάβουμε νέα σας.

Γιατί πρέπει να επαληθεύσω τον λογαριασμό μου;

Οι διαδικασίες επαλήθευσης αποσκοπούν στην προστασία από την απάτη, τη νομιμοποίηση εσόδων από παράνομες δραστηριότητες και την κλοπή ταυτότητας.

Κάθε σοβαρό καζίνο που έχει λάβει άδεια από τις αρμόδιες αρχές, πρέπει να συμμορφώνεται με αυτούς τους κανονισμούς, οι οποίοι είναι τυποποιημένοι σε ολόκληρο τον κλάδο.

Όλα τα έγγραφα που μας στέλνετε αποθηκεύονται σε ασφαλές περιβάλλον και είναι προσβάσιμα μόνο από εξουσιοδοτημένο προσωπικό.

Τα έγγραφα και οι πληροφορίες σας δεν θα κοινοποιηθούν ποτέ σε τρίτους.

Μπορώ να αλλάξω το νόμισμα του λογαριασμού μου;

Όχι, από τη στιγμή που έχετε ορίσει το νόμισμα του λογαριασμού σας, δεν μπορείτε να το αλλάξετε.

Πώς μπορώ να ανοίξω εκ νέου τον λογαριασμό μου;

Σε περίπτωση που έχετε κλείσει τον Λογαριασμό σας, ενδέχεται σε ορισμένες περιπτώσεις να είμαστε σε θέση να ανοίξουμε εκ νέου τον Λογαριασμό σας με τα ίδια στοιχεία λογαριασμού όπως και πριν, εάν μας το ζητήσετε. Σε τέτοιες περιπτώσεις, ενώ ο Λογαριασμός σας θα έχει τα ίδια στοιχεία λογαριασμού με πριν, θα υπόκειται στους Όρους Χρήσης που ισχύουν κατά την ημερομηνία του επανανοίγματος και τυχόν προηγούμενα δικαιώματα (συμπεριλαμβανομένων, αλλά χωρίς περιορισμό, των μπόνους ή των ενδεχόμενων κερδών) δεν θα ισχύουν πλέον.
