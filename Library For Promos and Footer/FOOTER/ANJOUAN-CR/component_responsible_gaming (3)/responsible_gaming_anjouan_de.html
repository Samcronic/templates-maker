Wie sieht das Problematische Spielverhalten aus?** ** Als problematisches Spielverhalten gilt ein Verhalten, das die Lebensweise, die Arbeit, die Finanzlage oder die Gesundheit einer Person oder ihrer Familie beeinträchtigt. Eine lange Teilnahme an Spielen ist für solche Personen kontraindiziert, da sie zu negativen Folgen führen kann. Im Jahr 1980 wurde die pathologische Glücksspielabhängigkeit offiziell anerkannt und in die Liste der psychischen Erkrankungen des internationalen Klassifizierungssystems DSM-IV und ICD-10 aufgenommen. Es wird definiert als eine anhaltende, sich wiederholende und häufig verstärkte Neigung zum Glücksspiel, trotz bestehender negativer persönlicher und sozialer Umstände, wie beispielsweise Schulden, zerbrochene Familienbeziehungen und berufliche Rückschläge. Regeln zum Verantwortungsvollen Spielen Wenn Sie die folgenden Regeln beachten, können Sie das Spiel ohne Sorge genießen: Beginnen Sie nur dann zu spielen, wenn Sie ruhig und konzentriert sind. Machen Sie regelmäßige Pausen. Legen Sie im Voraus fest, wie viel Geld Sie monatlich für das Spiel ausgeben können. Sobald Sie ein maximales Limit festgelegt haben, erhöhen Sie dies nicht weiter. Bevor Sie mit dem Spielen beginnen, legen Sie den maximalen Gewinnbetrag fest, bei dessen Erreichen Sie das Spiel beenden sollten. Legen Sie im Voraus fest, wie viel Sie sich leisten können, zu verlieren. Spielen Sie nicht unter Alkohol- oder Drogeneinfluss. Spielen Sie nicht, wenn Sie in einer depressiven Stimmungslage sind.
